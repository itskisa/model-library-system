# 📚 Library Management System

A console-based library management system built in Java that manages printed books, e-books and audiobooks.

## How to Use

Use the numbered options in the console to navigate the library menu.

* View available books
* View books by type
* Borrow a book
* Borrow a book by type
* Return a book
* Exit

## Features

* Library catalogue system.
* Printed books, e-books and audiobooks.
* Borrowing and returning system.
* Search by book title and author.
* Filter books by type.
* Input validation.
* Tracks whether books are currently borrowed.
* Console-based menu system.

## Book Types

* **Printed Book** — Page length and cover type.
* **E-Book** — Format, page length and file size.
* **Audiobook** — Narrator, audio length and file size.
